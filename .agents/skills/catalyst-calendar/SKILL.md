# Catalyst evidence

Use investment-chat and its shared snapshot first. Inspect news/filing/macro evidence for explicit dated events and cite the exact source. A financial period end is not an earnings announcement date; a historical FRED observation is not the next release schedule. Source identity, published time and confirmed/estimated status must be visible.

The current core does not provide a complete forward earnings/economic calendar. State that coverage gap. If the user asks for further web research, consult issuer IR, the Federal Reserve or BLS first-party calendar pages and identify source/time; keep those unarchived findings as supplementary context rather than passed trade evidence. Creating an investment recommendation still requires the shared assessed Decision.

Return a short event/date/source list when dates are actually verified. Do not infer there is no upcoming catalyst from empty provider data. Unknown event timing cannot silently pass a pre-trade catalyst check.
