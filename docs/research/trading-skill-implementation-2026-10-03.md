# Trading Skill 实现与验收

日期：2026-10-03。代码实施与隔离验收已完成；真实账户的连接、权限与数据覆盖须独立验收。
本文件不保存个人账户、资产金额、持仓数量、原始流水或密钥。

| 分派权利与现金账本 | 显式除息／付款／可用时间事件 | 除息前股数锁定美元应收，卖出不丢权利、新买不取得旧权利；拆股不改变应收；实际可用后才成为购买力 |

公司 TTM/DCF 内在价值估值、ETF 成分穿透、借券/做空、自动下单、无人值守
扫描不在当前已验证能力中。总回报必须包含 NAV 与分派；资料不足不推断无事件。

复审覆盖同股分属两模式、长期仓位 80% 与独立波段额度、部分成交与待撤单、
报价过期、净股数未变的卖买往返、失效卡数字抑制、费用后现金/仓位、未知行业
不阻碍可验证减仓，以及 10% 回撤时暂停新风险。未成交卖款不释放现金或同卡
仓位空间，模式归属和首次启动不能由空的近期成交响应推断。
分派回放区分权利形成、应收净值与现金可用时间，付款转换不重复增加净值；
缺少事件日期、份额单位或来源则拒绝准入。金额是税前总额，未模拟预扣税或
用户实际净到账；特殊大额、股票分派与 due-bill 规则不在已支持合同中。

历史回放以 100,000 USD 起步、单模式、完成日信号后下一日收盘理想化执行；
卖款保守延后 5 个已发布交易日释放，并非实现历史法定结算日历。报告明确列出
个人小账户整数股／最低费用、真实已有持仓、其他模式、行业、外部现金流、
挂单、真实行情/费用/tick/FX 等未模拟因素。该净曲线不代表个人账户收益。

实际来源审核与策略采用分别由用户确认；输入 JSON 的来源/hash/标志不认证
行情。`market_validated` 与 `source_authenticated` 均保持 false，人工审核记录
也不证明来源真实或样本外确实未被看过。本次没有真实历史数据策略准入、
个人策略采用、SDK 实装或真实 IBKR 验收。相应入口与[步骤](../STRATEGY_VALIDATION.md)
已实现；未来接入需新账户/报价和本人 Review。代码测试不证明盈利或全局最优。
