# Trading Copilot 0.6.1

This maintenance release keeps the manual advisor workflow from 0.6.0 and
strengthens the boundary between reusable public code and private instance data.

- Public manifests use project attribution without personal contact details.
- Research documents use portable paths and product contracts instead of
  recording an individual's account context or conversation preferences.
- Repository checks and release verification inspect content for private paths,
  account identifiers, contact details and credential patterns. Findings never
  echo matched values. An optional local denylist adds instance-specific checks.
- Synthetic test data and public market evidence remain available. Personal
  databases, credentials, configuration and transaction records stay local.

See [publication privacy](../PUBLICATION_PRIVACY.md) for the verification process
and the separate handling required for historical GitHub references and caches.
