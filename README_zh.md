# Trading Copilot

直接在 Claude Code 或 Codex 中问投资问题，得到简短中文建议；后台保存证据和你明确说已完成的操作。无需生成长报告。

范围：美股/ETF、纳斯达克100和综合指数、QQQ/QQQM、中国人民币投资金条/金币。日线、波段、长期配置；只用免费数据，允许免费注册和 API Key。

```powershell
.\scripts\start.ps1 -Client claude
.\scripts\start.ps1 -Client codex
```

[安装与免费 Key 配置](docs/INSTALL.md) · [数据来源与缺口](docs/mcp-fallback.md) · [方案和验收边界](docs/research/conversation-copilot-plan-2026-09-06.md)

你可以说：

- “分析 QQQ，适合长期持有吗？”——获取本次数据、校验、保存建议，给出结论和来源。
- “现在适合积累金条吗？”——分析上金所基准；具体购买还需商家、产品和含费报价。
- “我已经买了 2 股 QQQ……”——自动记账；缺少成交价等必要信息时先记待补全。
- “我想买 QQQ。”——意向，不增加持仓。
- “上一笔记错了……”——通过更正事件修改，保留历史。

同一仓库的两个客户端共享 SQLite。旧 Markdown 推荐记录不会变成真实交易。未说明手续费就保留未知；人民币和美元分别核算；仓位记录不完整时不输出精确配仓比例。

数据成功返回不等于可靠：检查交易日、复权、时间、来源独立性和冲突。免费覆盖不足、来源过期或冲突时暂停相关具体建议，保留已取得的分析依据。上金所价格不是银行或商家的金条卖价，指数点位也不是 ETF 成交价。

默认会话输出约 4–6 行，包含建议、依据、再观察条件、数据日期和来源。/analyze 仅在明确要求深入分析时启动；长报告按需生成。
