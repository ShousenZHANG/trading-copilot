# Trading Copilot

直接在 Claude Code 或 Codex 中问投资问题，得到简短中文建议；后台保存证据和你明确说已完成的操作。无需生成长报告。

范围：注册美股 ETF、显式开启并经来源确认身份的美国普通股、纳斯达克指数基准，以及人民币计价的上金所 Au99.99。公共研究使用免费数据；可选 IBKR 只读报价需要核实实际行情权限。支持长期与波段研究，允许免费注册和 API Key。

```powershell
.\scripts\start.ps1 -Client claude
.\scripts\start.ps1 -Client codex
```

[安装与免费 Key 配置](docs/INSTALL.md) · [数据来源与缺口](docs/mcp-fallback.md) · [方案和验收边界](docs/research/conversation-copilot-plan-2026-09-06.md)

你可以说：

- “分析 QQQ，适合长期持有吗？”——获取本次数据、校验、保存建议，给出结论和来源。
- “扫描候选股，找波段机会。”——采集配置候选池与基准，计算趋势、动量、量能及触发／失效参考价格，结合财报、新闻、宏观与反方证据。
- “给我可人工执行的买卖方案。”——采用规则后，由代码结合新鲜只读账户、实际报价、费用与资金限制生成交易卡，人工 Review 后再次刷新。
- “现在适合积累金条吗？”——分析上金所基准；具体购买还需商家、产品和含费报价。
- “我已经买了 2 股 QQQ……”——自动记账；缺少成交价等必要信息时先记待补全。
- “我想买 QQQ。”——意向，不增加持仓。
- “上一笔记错了……”——通过更正事件修改，保留历史。

同一仓库的两个客户端共享 SQLite。旧 Markdown 推荐记录不会变成真实交易。未说明手续费就保留未知；人民币和美元分别核算；仓位记录不完整时不输出精确配仓比例。

数据成功返回不等于可靠：检查交易日、复权、时间、来源独立性和冲突。免费覆盖不足、来源过期或冲突时暂停相关具体建议，保留已取得的分析依据。上金所价格不是银行或商家的金条卖价，指数点位也不是 ETF 成交价。

默认会话输出约 4–6 行，包含建议、依据、再观察条件、数据日期和来源。买入数量与限价只来自策略引擎对你在 config/user.toml 中采纳的规则的计算（见 ADR-0004），不承诺任何收益。

具体数量需要依次完成：私人配置、真实回测与规则采用、该账簿的完整持仓声明、当前快照；黄金还需本人观察的商家含费报价。完整操作步骤见 [安装教程](docs/INSTALL.md#adopt-a-rule-and-request-engine-orders)。黄金定投节奏未回测；历史曲线只衡量持有黄金的表现。

默认给模型的账户内容已脱敏，原始流水留在本地。[IBKR 只读接入](docs/IBKR.md)默认关闭，真实账户连接需另行验收。长期趋势和波段突破模板支持股票与 ETF；需另行完成[历史、费用、样本外验证与本人采用](docs/STRATEGY_VALIDATION.md)，再计算资金交易卡。研究参考价不作为可执行限价，本次代码升级未替个人账户采用策略。不会承诺盈利。

`/watchlist` 写入本机私有的 data/watchlist.local.md，公开的 data/watchlist.md 只提供受支持示例。当前没有无人值守扫描器或自动下单。

开发、测试、共享配置和备份命令见 [README](README.md)。研究用途及条款见 [DISCLAIMER](DISCLAIMER.md)。
