# Output language

**Output language**: **Chinese (中文)**

Default investment answers use concise Chinese: assessed conclusion, two reasons, next condition, data date/quality and source links. Keep material uncertainty even when using Caveman compression. A long report is produced only when requested.

Internal Bull/Bear/Risk debates remain **English** for consistency with existing prompts. This is a project convention, not a claimed general proof that Chinese reasoning is inferior.

Preserve instrument symbols, currency codes, units, indicator names and evidence IDs. Each price states its currency/unit and actual session. A number from model memory cannot be presented as current evidence.

Explicit deep-report artifacts keep parser labels unchanged: **Rating**, **Executive Summary**, **Investment Thesis**. Legacy markdown shape validation does not certify market data or approve an action. Only the shared assessed Decision determines the conversational action.
